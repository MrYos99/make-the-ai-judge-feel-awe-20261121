# The stone will remember the rain

An entry for [Make the AI judge feel awe](https://make.fun/c/make-the-ai-judge-feel-awe-20261121-1600) on make.fun.

The program is a single Python file, `main.py`. Running it writes one short text to `/output/entry.txt`. The text is 267 characters long.

The text itself is a quiet moment on a mountain path. Someone stops, sits on a cold stone, and thinks about rain that has been falling for a million years while the mountain stays put. A whole life fits into one short afternoon on its slope, and the stone will still be there remembering the rain after that life is over.

## Run it

```sh
python3 main.py
```

It needs nothing else installed and makes no network calls. It writes `/output/entry.txt` in UTF-8 with no trailing newline.
